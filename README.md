# Simple C Line Editor

## Team Members
Ankita
vijaya Lakshmi

## Data Structure Choice
* **Dynamic Array of Strings (`char** lines`)** for $O(1)$ fast indexing and efficient line access.

## Implemented Features
1. Insert a line (`I`)
2. Delete a line (`D`)
3. Display document (`P`)
4. Save file (`S`)

## Compilation & Run Instructions
```bash
gcc main.c -o editor
./editor
